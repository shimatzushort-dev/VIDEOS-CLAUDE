COMMANDS (work on Windows, Mac and Linux)
Run them in a terminal opened in your project folder.
Windows: in the folder, click the address bar, type cmd, press Enter.

# 0) Install ffmpeg once
Windows:  winget install Gyan.FFmpeg
Mac:      brew install ffmpeg

# 1) Word timings: install faster-whisper once (needs Python from python.org)
pip install faster-whisper
python 03_audio/align_words.py 03_audio/narration.mp3

# 2) Preview: in Blender, set Output to FFmpeg Video (MPEG-4), render, then add the voice
ffmpeg -i preview.mp4 -i 03_audio/narration.mp3 -c:v copy -c:a aac -shortest preview_with_voice.mp4

# 3) Final export: PNG frames + voice -> MP4
ffmpeg -framerate 24 -i 05_output/final_frames/f_%04d.png -i 03_audio/narration.mp3 -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -shortest 05_output/MyShort.mp4

# 4) Quick partial export while it renders (first 45 s = 1080 frames)
ffmpeg -framerate 24 -i 05_output/final_frames/f_%04d.png -i 03_audio/narration.mp3 -frames:v 1080 -c:v libx264 -crf 16 -pix_fmt yuv420p -c:a aac -shortest 05_output/MyShort_first45s.mp4
